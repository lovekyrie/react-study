# Learning Journal: 2026-07-11

## Q1: 配了 antfu/eslint-config 后，保存会改 JSX 换行，但原先格式并不报错？

**Context**: `src/lessons-common/01-jsx/JsxDemo.tsx`、`eslint.config.js`

**Key points**:

- antfu 用 ESLint 做格式化，风格规则可 auto-fix
- IDE 常静默 style 规则（不报红），保存时仍 `fixAll.eslint`
- JSX 多行拆分通常来自 `style/jsx-one-expression-per-line`

**Details**: [../knowledge/tooling/antfu-eslint-format-on-save.md](../knowledge/tooling/antfu-eslint-format-on-save.md)
